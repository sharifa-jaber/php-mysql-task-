# PHP & MySQL User Status Toggle

تطبيق ويب تفاعلي لإضافة بيانات المستخدمين (الاسم والعمر) وتخزينها في قاعدة بيانات MySQL، مع إمكانية تبديل الحالة (`0` / `1`) وتحديثها في الواجهة وقاعدة البيانات فوراً دون إعادة تحميل الصفحة.

## 🔗 رابط الموقع الحي (Live Demo)
http://smart-metho.infinityfree.me

## 🛠️ التقنيات المستخدمة
* **HTML & CSS:** تصميم الواجهة والنموذج والجدول.
* **PHP:** معالجة البيانات والاتصال بقاعدة البيانات.
* **MySQL:** تخزين السجلات وحفظ حالة كل مستخدم.
* **JavaScript (Fetch API):** تحديث الحالة في الصفحة فوراً عند الضغط على زر Toggle.

## 📋 خطوات تنفيذ المشروع
1. **إعداد الاستضافة وقاعدة البيانات:** إنشاء حساب استضافة على InfinityFree وإنشاء قاعدة بيانات MySQL باسم `if0_43478772_Task`.
2. **إنشاء جدول البيانات:** إنشاء جدول `users` عبر phpMyAdmin بالأعمدة التالية: (`id`, `name`, `age`, `status`).
3. **بناء الواجهة الرئيسية (`index.php`):** تصميم نموذج إدخال الاسم والعمر في سطر واحد، وعرض السجلات المخزنة في جدول أسفل النموذج.
4. **برمجة التبديل الفوري (`toggle.php`):** إنشاء ملف خلفي يستقبل `id` السجل ويعكس قيمة `status` بين `0` و `1` في قاعدة البيانات، مع ربطه بـ JavaScript لتحديث الرقم في الصفحة مباشرة.
5. **الرفع والاختبار:** رفع الملفات إلى مجلد `htdocs` على الاستضافة والتأكد من عمل الإضافة والتبديل الفوري بنجاح.
